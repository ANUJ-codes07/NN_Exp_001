# Practical No. 1: Exploring Deep Learning Libraries and Performing Basic Tensor Operations Using TensorFlow

## Aim

To familiarize students with popular deep learning libraries and perform basic tensor creation and mathematical operations using TensorFlow.

## Data Source

Dataset: **Not Applicable**

This practical uses manually created tensors and NumPy arrays. No external dataset is required.

## Libraries Used

* TensorFlow
* NumPy

## Tasks Performed

The following tasks were completed:

1. Installed TensorFlow using pip.
2. Verified the TensorFlow installation.
3. Displayed the installed TensorFlow version.
4. Created a scalar tensor.
5. Created a vector tensor.
6. Created a matrix tensor.
7. Created a three-dimensional tensor.
8. Performed tensor addition.
9. Performed tensor subtraction.
10. Performed tensor multiplication.
11. Performed matrix multiplication.
12. Reshaped an existing tensor.
13. Converted a NumPy array into a TensorFlow tensor.
14. Studied TensorFlow, PyTorch, and Keras.
15. Compared their features, advantages, and applications.

## Project Results / Insights

The practical successfully demonstrated the fundamental concepts of TensorFlow tensors and tensor operations.

The following operations were successfully performed:

* Scalar, vector, matrix, and 3D tensor creation.
* Element-wise addition.
* Element-wise subtraction.
* Element-wise multiplication.
* Matrix multiplication.
* Tensor reshaping.
* Conversion of NumPy arrays into TensorFlow tensors.

The practical also showed that TensorFlow is suitable for building and deploying deep learning applications, PyTorch provides flexibility and is widely used for research, while Keras provides a simple high-level interface for rapid neural network development.
